# Cours-Prog

Dépôt d'exercices de programmation en C# pour les études à la **Haute École de la Ville de Liège (HEL)**.

## 📋 Présentation

**Cours-Prog** est un dépôt éducatif regroupant une collection d'exercices et de projets en **C#** réalisés dans le cadre de la formation à la **Haute École de la Ville de Liège**. Ce projet contient des exercices variés couvrant différents sujets de programmation avec des implémentations pratiques.

## 🛠️ Technologies

- **Langage**: C# (.NET)
- **IDE**: Visual Studio 2022+
- **Type de projet**: Exercices éducatifs / Travaux pratiques
- **Licence**: MIT License

## 📚 À propos de HEL

La **Haute École de la Ville de Liège** est une institution d'enseignement supérieur proposant des formations en informatique et technologies. Ce dépôt contient les exercices pratiques réalisés dans le cadre de l'apprentissage en programmation.

## 🚀 Mise en place

### 1. Cloner le dépôt

```bash
git clone https://github.com/AirWanFR/Cours-Prog.git
cd Cours-Prog
```

### 2. Ouvrir la solution

Ouvrez le fichier **MainMenu.slnx** avec Visual Studio :

```bash
# Avec Visual Studio (Windows)
start MainMenu.slnx

# Ou ouvrir manuellement
# Clic-droit sur MainMenu.slnx > Ouvrir avec > Visual Studio
```

### 3. Compiler le projet

**Avec Visual Studio :**
- Menu : `Générer` → `Générer la solution` (Ctrl+Maj+B)

**Depuis la ligne de commande :**
```bash
dotnet build
```

### 4. Exécuter les exercices

- Sélectionnez le projet de l'exercice souhaité
- Appuyez sur `F5` ou `Ctrl+F5` pour lancer le programme
- Ou clic-droit sur le projet → `Définir comme projet de démarrage`

## 📖 Sujets couverts

Chaque exercice est conçu pour explorer des concepts différents :

- ✅ Programmation Orientée Objet (POO)
- ✅ Structures de données
- ✅ Algorithmes et résolution de problèmes
- ✅ Manipulation de fichiers
- ✅ Gestion des erreurs et exceptions
- ✅ Interfaces et abstractions
- ✅ Et bien d'autres concepts essentiels

## 📝 Comment utiliser ce dépôt

1. **Comprendre les exercices** : Chaque dossier d'exercice contient une description du problème à résoudre
2. **Étudier le code** : Lisez et analysez les implémentations fournies
3. **Essayer par soi-même** : Avant de regarder la solution, tentez de résoudre l'exercice seul
4. **Tester et déboguer** : Utilisez les outils de Visual Studio pour bien comprendre le fonctionnement
5. **Experimenter** : Modifiez le code pour tester vos connaissances

## 💡 Conseils d'apprentissage

- **Lire le code** : Prendre le temps de comprendre chaque ligne
- **Commenter** : Ajouter des commentaires pour mieux comprendre la logique
- **Tester** : Créer des cas de test pour valider vos solutions
- **Déboguer** : Utiliser les points d'arrêt (breakpoints) pour suivre l'exécution
- **Pratiquer** : Réfaire les exercices régulièrement
